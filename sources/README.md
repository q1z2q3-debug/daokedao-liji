# sources　注疏底本

本目录存放《礼记正义》（十三经注疏本）已剥净的注疏文本，供各课撰写时取文。**不依赖 `/tmp`**——`/tmp` 反复被清空，曾多次导致整卷重取。

## 取文

```bash
python3 scripts/fetch_zhushu.py --juan 8      # 卷八 → sources/卷八-檀弓上-2139.txt
python3 scripts/fetch_zhushu.py --juan 9      # 卷九 → sources/卷九-檀弓下-2138.txt
```

页号随卷递减（陕西师大十三经站 `ssjdd.snnu.edu.cn/sbw/info/1034/<n>.htm`）：卷三 2144、卷四 2143、卷五 2142、卷六 2141、卷七 2140、卷八 2139、卷九 2138。

## 结构（取文前必读）

**part K = 疏(K) + 经注(K+1)**。每块的头是本节的疏，尾是下一节的经文＋郑注。故取某节材料，要「疏取本块头、经注取本块尾」。

底本**简繁混用**（「孙」「于」「为」常作简体），不要用繁体 anchor 硬 `rfind`；取文前先整块打印核对。

一块含两条经文的情形常见（如卷八 294 与「读赗」、297 与「宾客至无所馆」），此时按**经文条目**分节，不按疏块分节；无疏之条直接注明「底本此节无疏文」。
