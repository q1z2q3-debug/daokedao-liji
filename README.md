## 是什么

《道可道之论语》写到《乡党》，写完孔子一日之容，只给了样子，没给理由。理由在《礼记》。这一部紧接而立：上一部问「怎么做」，这一部答「为什么这样做」。

一课一节，依郑注分节；课号 `LJ001` 起连排。四十九篇依郑目次第，不改篇题。

《大学》《中庸》已有别本，此处只在原第（第四十二、第三十一）列目，不再撰课。
