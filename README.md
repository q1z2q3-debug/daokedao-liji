# 润泽说 道可道之礼记

> 《礼记》四十九篇通释读本。底本经文依郑玄注本次第，注取郑玄，疏参孔颖达，集说参陈澔。
> 作者：润泽（润泽博士）· 在线读：<https://q1z2q3-debug.github.io/daokedao-liji/> · v0.1.2（曲礼上 一·一至一·九，八课）

## 是什么

《道可道之论语》写到《乡党》，写完孔子一日之容，只给了样子，没给理由。理由在《礼记》。这一部紧接而立：上一部问「怎么做」，这一部答「为什么这样做」。

一课一节，依郑注分节；课号 `LJ001` 起连排。四十九篇依郑目次第，不改篇题。

《大学》《中庸》已有别本，此处只在原第（第四十二、第三十一）列目，不再撰课。

## 体例

- 一课十一节：解题、经文、字义与句读、今译、章旨、礼义（三层）、分寸与边界（五条「不可」）、存疑（五条）、跨典、双卡、图。
- 四层分离：【经】原文、【训】字义句读、【义】章旨礼义、【教】分寸边界。一段只归一层。
